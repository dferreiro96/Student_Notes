# Student Grades / Notas de Estudiantes

A Python CLI program to manage student grades: add students, list them, sort by name or grade, and calculate average, highest, and lowest grade.

Un programa de línea de comandos en Python para gestionar notas de estudiantes: añadir estudiantes, listarlos, ordenarlos por nombre o nota, y calcular el promedio, la mejor y la peor nota.

## Features / Funcionalidades

- Add students with their grades / Añadir estudiantes con sus notas
- List all students and grades / Listar todos los estudiantes y sus notas
- Sort by name or by grade / Ordenar por nombre o por nota
- Calculate average, highest, and lowest grade / Calcular promedio, mejor y peor nota
- Input validation (numbers, ranges, duplicate names) / Validación de entradas (números, rangos, nombres duplicados)
- Clean menu-driven interface / Interfaz con menú claro
